Horse name search modes

🔍 Text Search Direct text match

Finds horses whose name contains exactly what you type. Fast and precise. e.g. typing "Desert" finds Desert Crown, Desert Hero etc.

✨ AI Search Semantic / concept match

Uses AI to find horses whose names are thematically related to your search. e.g. "music themed" finds Symphony, Maestro, Encore, Jazz; "royal themed" finds Crown Jewel, Palace Guard, King's Man.

AI Search takes a few seconds. Results are cached for the day so repeated searches are instant.
